# 特斯拉蓝牙钥匙 · HTML 产品原型

视觉方向：用户选定图 2，深色车机风格。此阶段不包含 Android 工程、真实蓝牙或车辆控制。

## 预览

在项目根目录运行 `python3 -m http.server 8796 --bind 127.0.0.1`，访问 `http://127.0.0.1:8796/prototype/`。也可直接打开 index.html；所有资源均本地保存。

## 可评审流程

- 车辆：俯视车图，前备箱、后备箱、解锁与锁车。
- 我的：管理蓝牙钥匙、添加钥匙、外观与设置。
- 外观：深色车机版 / 经典按钮功能版；模式选择保存在当前浏览器。
- 配对：VIN 校验或演示车辆 → 搜索 → 选车 → 实体卡 / 车机确认提示 → 模拟成功；包含失败重试。
- 设置：前备箱二次确认开关。
- 桌面左侧可切换已连接、未连接、首次使用。手机打开显示纯 App 页面。

## 范围与待确认事项

所有连接、车辆及命令状态均为演示，文案中的已完成不代表真实车辆执行。真实开发需要确认车型年份、手机型号、命令权限和实际车端反馈。后备箱关闭按钮仅为产品意图，是否显示需按实车能力决定；前备箱不提供关闭命令。车门位置不提供未经验证的单门弹开控制。

视觉资源：车辆图为 AI 生成；图标来自 Bootstrap Icons 1.11.3，MIT，见 assets/icons/LICENSE。UI 使用系统字体。
