# 官方版皮肤（0.1.12）

用户提供 Tesla 控制页截图作为布局参考：大幅俯视车辆、前备箱在车头、车锁在车顶、后备箱在车尾。
“官方版”是用户指定的皮肤名称，不表示此 App 由 Tesla 官方发布。

## 入口与持久化

“我的 → 换肤”，提供官方版（official）、车机版（cockpit）、功能版（classic）。沿用 `ui` SharedPreferences 的 `skin` 键，切换仅影响呈现，不修改密钥、连接或协议会话。保留用户原有选择。

## 官方版页面

- 标题“控制”，右上角沿用真实蓝牙连接状态。
- 独立银色车身俯视素材，保留已有 App 的车辆配色；无蓝色边框卡片。
- 三个操作区依图像显示尺寸计算位置，分别在图像高度 17%、54%、79% 处，避免不同屏幕下按钮错位。
- 车锁在车辆反馈为已解锁时显示“锁车”，已锁车/部分解锁时显示“解锁”，未知时显示“车锁”。
- 车头/车尾显示前后备箱状态；断连或未知状态不推断开关结果。
- 空调开关与刷新沿用既有功能；较短屏幕可纵向滚动，底部导航固定。
- 未连接或正忙时禁用车辆控制；没有模拟操作。
- 不加入参考图中的闪灯、鸣笛、启动、通风或胎压入口，因为当前协议功能尚未接入。

## 图像来源

使用内置 imagegen，以用户截图作为构图参考生成单独车辆素材，写入 `app/src/main/res/drawable-nodpi/car_official.png`。
提示词要点：正俯视 Model Y、车头向上、银色车漆、深色玻璃车顶、深石墨背景、完整车辆、无 UI 文字及按钮。
布局及按钮为原生 Android View，未将界面整体做成不可交互图片。
